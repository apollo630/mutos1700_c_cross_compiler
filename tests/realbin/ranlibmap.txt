# ranlibmap.txt - a map of the real MUTOS 1700 ranlib (mutos/mutos_bin/ranlib.golden.base64.txt)
#
# The binary (0407, text 1a8a, data 1c32 bytes with the BSS to 3d54) is
# stripped; the names below are v7's (v7/ranlib/ranlib.c, which is nm's
# code), found by the strings each function passes, the calls it makes and
# its position. It is crt0, then ranlib.o - v7's ranlib.c, its five
# functions in source order -, then libc.a from text 0580 (fseek; the
# others matched by ranlibdis.py against libc.a's objects). ranlibdis.py
# reads this file.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/ranlib/ranlib.c): same - compared, does what v7's does
#                                      libc - libc.a's, as far as the port re-enacts it
# Port: ported - in src/mutos_ranlib/ranlib.c, read from the text at that
#       offset (libc.a's: only where the port re-enacts what ranlib sees of
#       it, stdio's slots; the rest is the host's)
#
# Every function was compared instruction by instruction. Common to all:
# the headers are bytes (ar_hdr 26, exec 16, nlist 12), the longs have
# their high word first (arp.ar_size, off, oldoff, tab[].cloc,
# offdelta), the symbol's type is read as a word and its N_EXT bit (040)
# tested, the messages begin with "nm: " (v7's ranlib is nm's code), and
# arp and exp lie one behind the other at 1c34 and 1c4e (arp.ar_name of 14
# bytes runs on into the header when it has no 0 - "nm: %s-- no name
# list" prints it so).
# ---- crt0.o
T 0000 start       crt0       -       crt0.o
# ---- ranlib.o
T 00b6 _main       same       ported  per archive: fopen "r", the magic (0177545), the members via nextel(); the a.out magics 0407 0410 0411 0405 only; the symbols with N_EXT set and a type that is not 0 into tab[700] (stash()); then fixsize(), the temporary "__.SYMDEF" written ("w"), "ar rlb %s %s %s" or "ar rl %s %s" through system(), fixdate()
T 0346 _nextel     same       ported  oldoff = off; fseek(fi, off, 0); fread 26 bytes into arp; off = ftell() + size, an odd size rounded up
T 03d8 _stash      same       ported  tab[tnum] gets the 8 bytes of the name and oldoff (tnum: "symbol table overflow" and exit 1 at 700)
T 0448 _fixsize    same       ported  offdelta = 12 * tnum + 26 (less the old table's size and header if the first member is "__.SYMDEF"); added to every cloc; the first member's name copied to firstname[17] otherwise; returns "new"
T 04fc _fixdate    same       ported  open(archive, 1), write time() + 5 at offset 16 (the date of the first member); "can't reopen %s" otherwise
