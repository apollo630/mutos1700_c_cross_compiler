# edmap.txt - a map of the real MUTOS 1700 ed (mutos/mutos_bin/ed.golden.base64.txt)
#
# The binary (0407, text 0000..2d02, data 2d02..2dec, BSS to 4102) is stripped; the
# names are v7's: v7/ed/ed.c with the two MUTOS changes (src/mutos_ed/README.md),
# compiled with the project's own cc -O -s and linked with libc.a, is the binary
# byte for byte - the offsets below are that build's symbol table. It is crt0, then
# ed.o, then libc.a from text 2556 (exit). eddis.py reads this file.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status: v7    - v7's function, instruction for instruction (the rebuild)
#         mutos - v7's with the MUTOS change (the rebuild)
#         libc  - libc.a's
# Port:   ported - in src/mutos_ed/ed.c; for libc.a: as far as ed sees it
#
# The line table is malloc()ed at 0x4104 (measured), the break before it 4102.
