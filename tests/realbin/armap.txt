# order -, then libc.a from text 0f32 (fprintf; the others matched by
# ardis.py against libc.a's objects). ardis.py reads this file; artables.py prints
# the data (sys_errlist).

#         "D <data offset> <name> [<note>]" for data.

# Common to all 33: v7's code as it is. The header (arbuf) is 26 bytes of
# which the longs have their high word first and uid and gid are signed
# chars ("ar t" shows them so); the option counters flg[] are signed chars
# that wrap; stat is the 30-byte MUTOS struct stat. A function that
# prints does it with fprintf(stderr, ...) except usage() (printf, stdout)
# and the listings (stdout).
