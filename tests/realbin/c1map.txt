# c1map.txt - a map of the real MUTOS 1700 c1 (mutos_bin/c1.golden.base64.txt)
#
# The binary is stripped (no symbol table). Names come from the strings each
# function prints, its calls, and its position: the functions follow
# v7/cc/c10.c, c11.c and c12.c in source order, as v7's makefile links them
# (c10.o c11.o c12.o c13.o table.o), then libc.a. c1dis.py reads this file;
# the libc.a functions (text 5b46 on) it names itself, by matching libc.a's
# objects (tests/mutos1700_libc) against the text.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/cc): same       - compared, does what v7's does
#                         delta      - compared, v7's code with the noted changes
#                         x86        - read, rewritten for the 8086 / MUTOS syntax
#                         new        - no v7 counterpart
#                         unread     - placed by order and strings, not compared yet
# Port (docs/C1_PORT_PLAN.md): ported - in src/mutos_cc/c1port/, decompiled
#                                       from the text at that offset
#                              -      - not yet
# v7 functions with no counterpart here: oddreg (no PDP-11 register pairs),
# psoct (numbers are printed in decimal, "%d.").
#
