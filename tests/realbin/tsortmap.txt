# tsortmap.txt - a map of the real MUTOS 1700 tsort (mutos/mutos_bin/tsort.golden.base64.txt)
#
# The binary (0407, text 1b6e, data 1b6e..1dca, BSS to 2280) is stripped; the names below are v7's
# (v7/tsort/tsort.c), found by the strings each function passes, the calls it makes and
# its position. It is crt0, then tsort.o - v7's tsort.c, its eight functions -, then
# libc.a from text 03cc (fopen) (tsortdis.py matches the other functions against
# libc.a's objects). tsortdis.py reads this file.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/tsort/tsort.c): same - compared, does what v7's does
#                                      libc - libc.a's, as far as the port re-enacts it
# Port: ported - in src/mutos_tsort/tsort.c, read from the text at that
#       offset (libc.a's: only where the port re-enacts what tsort sees of
#       it - stdio's buffering and status values; the rest is the host's)
#
# Common to all: the words are 16 bits wide, struct nodelist is 8 bytes
# (nextnode, inedges, name, live), struct predlist 4 (nextpred, pred).
# main() has no exit(): AX is the exit status. Its frame (bp-6e): follows[50],
# precedes[50], x, j, input.
