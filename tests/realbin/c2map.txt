# c2map.txt - a map of the real MUTOS 1700 c2 (mutos_bin/c2.golden.base64.txt)
#
# The binary (0411, text 17792, data 1476, BSS 2908 bytes) is stripped;
# the names below are v7's (v7/cc/c20.c, c21.c) where the function has a
# counterpart there, found by the strings each function passes, the calls
# it makes and its position, and the port's (src/mutos_cc/c2port/) for
# the new ones. It is crt0, then c20.o - v7's c20.c in source order,
# reducelit() gone -, then c21.o - v7's c21.c in source order, toofar()
# with ilen() and adrlen() in it, addsob()'s place taken by shortbr(),
# convreg() and bytereg() new after isreg(), source(), setcc() gone -,
# then nine new functions after natural(), then libc.a from text 3484
# (freopen; the others matched by c2dis.py against libc.a's objects).
# c2dis.py reads this file; c2tables.py --strings prints the strings,
# --optab the opcode table.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/cc/c2*.c): same  - compared, does what v7's does
#                               delta - compared, v7's code with the noted changes
#                               x86   - v7's purpose, rewritten for the 8086
#                               new   - no v7 counterpart
#                               libc  - libc.a's, as far as the port re-enacts it
# Port: ported - in src/mutos_cc/c2port/c20.c or c21.c (libc.a's in
#       c2lib.c), read from the text at that offset
#
# Every function was compared instruction by instruction. Common to all:
# the ops are the MUTOS assembler's (c2tables.py --optab: optab[] with 64
# entries, OPHS 79), a node is 16 bytes (v7's 14 and two mask bytes),
# regs[] has 14 entries of 32 bytes (regs[12] RT1 the source, regs[13]
# RT2 the destination: the MUTOS order "op dst,src"), constants are
# "*n." (decimal), a branch redirected to another target takes its code
# with its label number. Switches: rmove()'s, toofar()'s and regmask()'s
# are jump tables in the text (1441, 1913, 2c24), convreg()'s, bytereg()'s
# and compare()'s too (1d8b, 1dbb, 229e), indexopt()'s (262e); pinned()'s
# is hashed (op % 2: table 312c, then op / 2 compared).
#
