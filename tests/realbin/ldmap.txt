# ldmap.txt - a map of the real MUTOS 1700 ld (mutos_bin/ld.golden.base64.txt)
#
# The binary (0411, text 12480, data 952, BSS 36382 bytes) is stripped;
# the names below are v7's (v7/ld/ld.c), found by the strings each
# function passes, the calls it makes and its position. It is crt0, then
# ld.o - v7's ld.c, its 37 functions in source order and one new one,
# bytrel(), after load2td() -, then libc.a from text 20c0 (printf; the
# others matched by lddis.py against libc.a's objects). lddis.py reads
# this file; ldtables.py --strings prints the strings.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/ld/ld.c): same  - compared, does what v7's does
#                              delta - compared, v7's code with the noted changes
#                              new   - no v7 counterpart
#                              libc  - libc.a's, as far as the port re-enacts it
# Port: ported - in src/mutos_ld/ld.c (libc.a's in ldlib.c), read from the
#       text at that offset
#
# Every function was compared instruction by instruction. Common to all:
# a symbol's type is read and compared as a word - its type byte and the
# spare byte together (EXTERN+UNDEF is 0x0020) -, the longs (archive
# times and sizes, liblist[], tab[].cloc) have their high word first, and
# all of v7's rflag, arflag and dflag code is gone. Switches: main()'s is
# hashed (c % 6, then c / 6 compared), load1arg()'s, middle()'s and
# load2td()'s are jump tables in the text (0840, 0ddb, 1512).
#
# ---- crt0.o

# ---- ld.o
