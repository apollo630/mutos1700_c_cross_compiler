# cppmap.txt - a map of the real MUTOS 1700 cpp (mutos/mutos_bin/cpp.golden.base64.txt)
#
# Unlike the other originals the binary keeps its symbol table (267
# symbols; cpptables.py --symbols prints it): the names below are the
# binary's own. cpp.o ("@(#)cpp.c 1.6 12/12/86") is v7/cpp/cpp.c's
# functions in its source order, cpy.o ("@(#)yylex.c 1.3 12/12/86") is
# yylex(), tobinary() and yacc's yyparse() from v7/cpp/cpy.y and
# yylex.c, then libc.a from text 26c6. cppdis.py reads this file.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/cpp): same  - compared, does what v7's does
#                          delta - compared, v7's code with the noted changes
#                          new   - no v7 counterpart
# Port: ported - in src/mutos_cpp/, read from the text at that offset
#
# Every function was compared instruction by instruction; the switches
# (cotoken's at 0875, tobinary's at 2288, yyparse's at 250d and 2689) are
# jump tables in the text. The binary's parameters: BUFSIZ 512, SBSIZE
# 32000, symsiz 1000, buffer[] 128+512+512+128 with pbeg 128 into it, a
# name significant to 128 characters, COFF 0 with signed chars (a byte
# 0200..0377 indexes a table below its start).
#
