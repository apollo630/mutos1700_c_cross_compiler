# sizemap.txt - a map of the real MUTOS 1700 size (mutos/mutos_bin/size.golden.base64.txt)
#
# The binary (0407, text 11b2, data 11b2..12cc, BSS to 1782) is stripped; the names below are v7's
# (v7/size/size.c), found by the strings each function passes, the calls it makes and
# its position. It is crt0, then size.o - v7's size.c, its one function -, then
# libc.a from text 01ca (fread) (sizedis.py matches the other functions against
# libc.a's objects). sizedis.py reads this file.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/size/size.c): same - compared, does what v7's does
#                                      libc - libc.a's, as far as the port re-enacts it
# Port: ported - in src/mutos_size/size.c, read from the text at that
#       offset (libc.a's: only where the port re-enacts what size sees of
#       it - stdio's buffering and status values; the rest is the host's)
#
# Common to the function: the a.out header is a 16-byte local of main()
# (struct exec buf, zero at the start, stale between the files), the words
# are 16 bits wide, the sum of the three sizes a long (the high word first).
# ---- crt0.o
