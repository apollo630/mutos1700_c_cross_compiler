# c0map.txt - a map of the real MUTOS 1700 c0 (mutos_bin/c0.golden.base64.txt)
#
# The binary is stripped (no symbol table). Names come from the strings each
# function prints, its calls, and its position: the functions follow
# v7/cc/c00.c .. c04.c in source order, as v7's makefile links them
# (c00.o c01.o c02.o c03.o c04.o c05.o), then libc.a from text 4a1e. c0dis.py
# reads this file; the libc.a functions it names itself, by matching libc.a's
# objects (tests/mutos1700_libc) against the text.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/cc): same       - compared, does what v7's does
#                         delta      - compared, v7's code with the noted changes
#                         new        - no v7 counterpart
# Port (docs/C0_PORT_PLAN.md): ported - in src/mutos_cc/c0port/, decompiled
#                                       from the text at that offset
#
# The switch statements are hashed (value % N into a jump table of chains
# comparing the quotient) or plain jump tables; their cases were read off the
# tables. Every function was compared instruction by instruction.
#
