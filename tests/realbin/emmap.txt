# emmap.txt - a map of the real MUTOS 1700 em (mutos/mutos_bin/em.golden.base64.txt)
#
# The binary (0411: text 0000..6a00, data 0000..083a, BSS to 3310) is stripped and
# has no source. Its functions were found by matching the original ed's
# (edmap.txt: the rebuild) instruction for instruction, the names of the others
# are this project's. It is crt0, then em.o, then libc.a from text 613e (exit;
# stdio is linked for the -r echo). emdis.py reads this file.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status: ed     - the original ed's function, instruction for instruction
#         ed+    - ed's with the change in the note
#         new    - em's own
#         screen - the screen mode
#         libc   - libc.a's
# Port:   ported - in src/mutos_em/em.c; refused - the port refuses there
#
# The line table is malloc()ed at 0x3312 (measured), behind the bss.
