# makemap.txt - a map of the real MUTOS 1700 make (mutos/mutos_bin/make.golden.base64.txt)
#
# The binary (0411, text 16192 bytes, data 3288, bss 6430) is stripped; the
# names below are v7's (v7/make/), found by the strings each function passes,
# the calls it makes and its position. It is crt0, then make.o's 50
# functions - main.c, doname.c, misc.c, files.c, dosys.c in source order
# and gram.y's yylex, retsh, nextlin and yyparse -, then libc.a from text
# 27cc (fseek; the others matched by makedis.py against libc.a's objects).
# makedis.py reads this file; maketables.py prints and checks the data.
#
# Format: "T <text offset> <name> <status> <port> [<note>]" for code,
#         "D <data offset> <name> [<note>]" for data.
# Status (against v7/make/): same - compared, compiles with the project's
#                                   cc -O -Dunix to these very bytes
#                            yacc - yacc's skeleton, generated
#                            libc  - libc.a's, as far as the port re-enacts it
# Port: ported - in src/mutos_make/<file>, read from the text at that offset
#       mklib.c - the host's libc, shaped as libc.a's is (see that file)
#

# Common to all 50: v7's code as it is (the three differences in make.h: no
# METERFILE, MUTOS's struct nlist, NLEFTS 300). Every function begins with
# the stack check chkstk (3d1a) with its frame size in AX; when the frame
# would not fit the kernel is asked for more (a system call through the gate
# at data 2) and the process dies with SIGSEGV if it refuses - the port
# counts the frames (mk_enter/mk_leave) and refuses (mk_trap).
